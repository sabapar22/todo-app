# ✨ Daily Task Manager

## 📖 Overview

Daily Task Manager is a simple and interactive To-Do List web application developed using **HTML**, **CSS**, and **JavaScript**. The application allows users to manage their daily tasks efficiently by adding, completing, and deleting tasks in a user-friendly interface.

This project demonstrates the use of **DOM Manipulation**, **Event Handling**, **Dynamic Element Creation**, and **Responsive Web Design** using vanilla JavaScript.

---

## 🎯 Objective

The objective of this project is to build a mini interactive web application using JavaScript and DOM manipulation techniques. Users can organize their daily activities and track pending tasks through a simple and attractive interface.

## 📋 Functional Requirements

### 1. Add Task
The user enters a task in the input field and clicks the Add button or presses Enter.

### 2. Complete Task
Clicking on a task marks it as completed by applying a strikethrough effect.

### 3. Delete Task
Each task contains a Delete button which removes the task from the list.

### 4. Task Counter
The application displays the current number of tasks and updates automatically whenever tasks are added or removed.

## ⚙️ How the Application Works

### Step 1
The user enters a task in the input field.

### Step 2
The Add button triggers the `addTask()` function.

### Step 3
A new list item (`li`) is created dynamically.

### Step 4
The task is appended to the task list.

### Step 5
Clicking the task toggles the completed status.

### Step 6
Clicking Delete removes the task and updates the counter.

## ▶️ How to Run the Project
